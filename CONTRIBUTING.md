# Contributing Guide

Thank you for contributing to Open Agent Skills.

## Adding a New Skill

A new skill should include:

```
skill-name/

└── SKILL.md
```

The SKILL.md file should describe:

* Skill purpose
* Expected inputs
* Workflow steps
* Expected outputs
* Security considerations

## Quality Requirements

Contributions should:

* Solve a clear development workflow problem
* Provide reusable value
* Include documentation
* Avoid unsafe operations

## Security Requirements

Do not include:

* Hardcoded credentials
* Hidden network requests
* Destructive commands
* Instructions that bypass security controls

## Pull Requests

Please include:

* Description of changes
* Usage examples
* Testing information
* Security considerations

Maintainers will review contributions before merging.
