# Documentation Skill

## Purpose

Help developers create and maintain high-quality technical documentation.

## Use Cases

* README generation
* API documentation
* Developer guides
* Migration documentation

## Input

The agent may analyze:

* Source code
* Existing documentation
* API definitions
* Configuration files

## Workflow

## 1. Understand Project

Analyze:

* Purpose
* Architecture
* Main features
* User workflows

## 2. Generate Documentation

Create:

* Installation instructions
* Usage examples
* Configuration guides
* Troubleshooting sections

## 3. Review Documentation

Check:

* Accuracy
* Completeness
* Consistency

## Safety Guidelines

The agent must:

* Avoid inventing unsupported features
* Clearly identify assumptions
* Never expose confidential information

## Output

Documentation should be:

* Accurate
* Maintainable
* Developer-friendly
