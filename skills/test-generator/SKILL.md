# Test Generator Skill

## Purpose

Generate software tests based on source code and project requirements.

## Use Cases

* Unit test generation
* Integration test planning
* Edge case discovery
* Regression prevention

## Input

The agent may analyze:

* Source code
* Existing tests
* API specifications
* Expected behavior

## Workflow

## 1. Analyze Code

Identify:

* Functions
* Classes
* External dependencies
* Possible failure conditions

## 2. Generate Tests

Create tests for:

* Normal cases
* Edge cases
* Error handling
* Boundary conditions

## 3. Review Tests

Ensure:

* Tests are meaningful
* Assertions are valid
* No unnecessary complexity

## Safety Guidelines

The agent must:

* Never delete existing tests
* Never modify production code automatically
* Avoid generating destructive test cases

## Output

Provide:

* Test files
* Test explanation
* Coverage suggestions
